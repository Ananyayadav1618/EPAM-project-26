# XYZ Bank Diwali Coupon

## Overview

A beginner-level JavaScript project developed for XYZ Bank Diwali festival coupon generation.

## Features

- Welcome message for existing customers
- Hide coupon instructions after registration
- Generate Diwali coupon code using Customer ID
- Dynamic updates using JavaScript DOM manipulation

## Technologies Used

- HTML
- CSS
- JavaScript

## JavaScript Concepts Used

- Variables
- Functions
- DOM manipulation
- Events
- String methods
